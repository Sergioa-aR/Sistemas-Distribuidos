# Sistemas-Distribuidos
Repositorio para enviar trabajos 

# Reflexión sobre la actividad
1. ¿Qué ventajas encuentras en trabajar directamente en la nube con GitHub?
  Trabajar directamente en la nube con GitHub ofrece múltiples ventajas, especialmente en proyectos de desarrollo web.
  Permite acceder al repositorio desde cualquier lugar y dispositivo con conexión a internet, lo que facilita la continuidad
  del trabajo sin depender de un solo equipo.
   
2. ¿Qué desafíos tuviste al crear el sitio sin usar herramientas locales?
  Crear un sitio web sin utilizar herramientas locales puede presentar varios desafíos. Uno de los principales es la
  dependencia total de la conexión a internet, ya que cualquier interrupción afecta directamente la productividad. Además,
  el entorno en la nube puede ser más limitado en cuanto a configuraciones avanzadas o herramientas especializadas, lo que
  dificulta algunas tareas de desarrollo.
  
3. ¿Cómo podrías mejorar este sitio web en el futuro?
  En el futuro, el sitio web podría mejorarse significativamente mediante la implementación de un diseño responsivo que
  garantice una correcta visualización en dispositivos móviles. También sería importante optimizar la experiencia del usuario,
  mejorando la navegación y reduciendo los tiempos de carga. Se podrían añadir elementos interactivos utilizando JavaScript para
  hacer el sitio más dinámico y atractivo.
   
4. ¿Qué aprendiste sobre Sistemas Distribuidos al crear este sitio?
  Al crear este sitio web se pueden comprender varios conceptos fundamentales de los sistemas distribuidos. Por ejemplo, se evidencia
  la descentralización, ya que el proyecto no depende de una sola máquina sino de servidores remotos. También se observa cómo funciona
  la consistencia y sincronización de datos a través del control de versiones, asegurando que los cambios se reflejen correctamente.
